# Northstar 90

**A 90-Day Career & Life Operating System**

Northstar 90 is a lightweight, local-first dashboard for turning a career transition into a measurable 90-day operating rhythm. It combines daily priorities, career-funnel activity, research, health, recovery, weekly reviews, and a 90-day journey in one SQLite-backed app.

## Core workflow

- **Today** — Big 3 priorities, extra tasks, time tracking, energy and sleep
- **Weekly Map** — applications, Tier-1 roles, outreach, follow-ups, and time allocation
- **90-Day Journey** — three 30-day sprints with clickable daily history
- **Weekly Review** — an auto-generated data brief plus a focused reflection
- **Data Dashboard** — 7 / 30 / 90-day activity and time trends

Count-based tasks such as applications, outreach, and follow-ups support flexible quantities, while time-based work records actual minutes.

## Run locally

```bash
python server.py
```

Then open `http://localhost:8765`.

## Storage

Northstar 90 uses a local SQLite database. The database itself should not be committed to GitHub.
